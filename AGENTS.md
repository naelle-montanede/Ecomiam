# Consignes pour les agents IA
- Projet statique : HTML/CSS/JS sans framework, sans étape de build.
- Une issue = une branche = une PR. Ne modifie que les fichiers cités dans l'issue.
- Textes de l'interface en français, ton simple, phrases à la voix active.
- Les données de démo sont dans js/data.js ; ne jamais coder de prix en dur ailleurs.
- Accessibilité : labels sur les champs, focus visible, contraste suffisant.
- Avant de rendre la PR : ouvrir index.html, tester les 2 vues sur mobile (largeur 375 px).
